# CodeMind Frontend

Vue 3 前端提供认证、知识库管理、文档处理、语义检索、RAG 问答、问答反馈、知识地图、AI 定制练习和管理员中心。

知识库选择器使用“公共知识库”和“我的知识库”分组，并显示公共/私人标签。公共文档展示上传者；
普通用户只会看到自己上传文档的重建、取消和删除操作，管理员可管理全部公共文档并在“我的”页面
编辑公共知识库名称和描述。公共知识库本身不提供删除入口。

## 技术栈

- Vue 3 与 Vue Router
- Vite
- Element Plus
- Axios
- AntV G6 知识地图画布
- Mammoth、Marked 与 DOMPurify 文档预览

## 页面路由

| 路径 | 页面 | 说明 |
| --- | --- | --- |
| `/` | `HomeView` | RAG 问答和来源展示 |
| `/search` | `SearchView` | 独立语义检索、召回参数和来源跳转 |
| `/documents` | `DocumentUploadView` | 上传、进度和处理状态 |
| `/library` | `DocumentLibraryView` | 文档筛选、取消处理、重建和删除 |
| `/documents/:id/view` | `DocumentViewerView` | 原始文档预览 |
| `/documents/:id/chunks/:chunkId` | `DocumentDetailView` | 片段查看和定位 |
| `/history` | `QaHistoryView` | 问答历史和来源快照 |
| `/mind-map` | `MindMapView` | 知识地图生成与学习 |
| `/quiz` | `QuizView` | 多知识库 AI 出题、在线作答与提交结果 |
| `/me` | `MeView` | 私人知识库管理和最小公共知识库管理 |
| `/me/ai-models` | `AiModelSettingsView` | 个人大模型配置、测试和启停 |
| `/admin` | `AdminView` | 管理员就绪状态、用户、公共文档和反馈管理 |
| `/forbidden` | `ForbiddenView` | 普通用户访问管理入口时的无权页面 |
| `/login`、`/register` | 认证页面 | 登录和注册 |

除首页和认证页面的公开外观外，业务路由通过用户 Store 和 JWT 状态保护；后端仍会独立校验所有资源归属。

AI 模型设置页只向后端提交 API Key，不直接请求模型服务，也不将密钥写入 `localStorage`。
保存后仅显示末四位掩码；配置必须测试成功后才能启用，停用或删除后恢复系统模型。

## 本地开发

```bash
cd frontend
npm ci
npm run dev
```

默认开发地址为 `http://localhost:5173`。普通接口根地址由 `VITE_API_BASE_URL` 控制；Docker 前端通过 Nginx 将 `/api` 代理到后端。

首页问答使用 `fetch` 消费 `POST /api/chat/stream` 的 SSE 响应。事件顺序为 `meta`、多个 `token`、`done`；
`meta` 提前返回来源，`token` 逐段更新回答，`done` 返回最终答案和问答记录 ID。流式请求使用浏览器原生
`AbortController`，切换问题或离开页面时会中止当前请求。

Docker 生产环境的 `nginx.conf` 已关闭 `/api/` 代理缓冲，并将读取超时设置为 300 秒，否则浏览器可能等到
完整回答生成后才一次性收到内容，无法体现流式效果。

生产构建：

```bash
npm run build
```

所有页面路由均懒加载。Element Plus 组件和消息 API 由构建插件按需导入，生产构建将 AntV G6、Element Plus 和文档预览依赖拆为独立异步 chunk。首屏只预加载入口与 Vue 运行时，合计约 `62.5 KiB gzip`；较大的业务依赖仅在打开对应页面后下载。详细记录见 [前端构建优化](../docs/前端构建优化.md)。

## 知识地图交互

当前 `MindMapView` 与 `MindMapCanvas` 已支持：

- 创建后台生成任务、显示阶段和逐步降频轮询。
- 页面切换后恢复同一知识库中的未完成任务，并丢弃旧任务迟到响应。
- 进入知识地图时先展示全部知识库的已生成地图列表，不自动打开某张历史地图。
- 展示节点类型、摘要、关键记忆点、学习建议、知识路径和来源。
- 节点相关资料检索、针对性提问和 AI 分支扩展。
- 搜索标题、摘要和关键记忆点并定位节点。
- 画布缩放、适应、重新布局、撤销重做、拖拽锁定、折叠和全屏。
- 地图历史创建、更新、打开和删除。
- 继续学习前确认当前知识点是“已掌握”还是“还需复习”，再定位下一个未掌握节点。
- 使用 G6 合并渲染层导出 PNG，可选择完整地图或当前视图；同时支持 SVG、JSON 和 Markdown 导出。
- 掌握知识点、加入复习和完成一轮学习时显示即时进度反馈。
- 大图交互使用子树与搜索文本索引，并只刷新发生变化的节点状态；连续输入搜索词时合并画布更新，减少大图选中、折叠和学习标记时的重复渲染。
- 使用 `localStorage` 保存本机节点掌握状态；该状态不会跨浏览器或设备同步。

知识地图正式生成流程调用 `/api/mind-maps/jobs` 和 `/api/mind-maps/jobs/{job_id}`。节点追问和扩展接口最长可等待 300 秒，前端请求超时设置为 6 分钟。

## AI 出题交互

- 公共知识库和我的私人知识库分组多选，最多同时选择 5 个。
- 支持 5～20 题、基础/进阶/挑战、主题关键词、指定题型或随机混合六类题型。
- 后台生成阶段展示资料抽取、AI 出题、结构校验和完成进度；刷新页面可恢复尚未结束的临时会话。
- 单选、多选、判断、填空、简答和情景应用分别使用对应作答控件，提交前页面拿不到正确答案。
- 提交后明确展示“客观题得分”，主观题可对照参考答案完成自评；结果支持全部、需复习和待自评筛选，以及逐题或批量折叠。
- 结果按当前用户保存在本标签页的 `sessionStorage` 中，刷新页面或同标签页查看来源后返回仍可恢复；原文链接默认在新标签页打开。
- 离开未完成练习会二次确认并清理服务端会话；已提交结果不写入服务端历史，关闭标签页后不再保留。
- 当前产品边界与后续优化统一记录在 [已知问题与后续计划](../docs/已知问题与后续计划.md)。

## 文档上传与预览

- 问答和上传默认选择当前用户的私人知识库；公共上传显示常驻警告，并在提交前确认文件名和目标库。
- 上传接口超时为 5 分钟，并通过 Axios 事件显示真实上传进度。
- 若上传响应超时，先到文档库确认是否已创建记录，避免重复提交。
- 状态轮询遇到临时网络错误会继续重试。
- 文档库可取消 `pending` 或 `processing` 任务，并显示 `cancelled` 状态。
- 文档库同时展示可访问的公共文档和本人私人文档，并根据后端 `can_manage` 权限显示操作按钮。
- 已完成的私人文档可在本人私人知识库之间移动，不支持直接跨私人/公共范围移动。
- 公共文档详情、片段和原文允许所有登录用户查看，并明确显示上传者。
- 原文预览通过受保护的 `/api/documents/{id}/content` 获取，不直接公开上传目录。

## 反馈与管理员中心

- 回答完成后和历史详情共用反馈组件，支持 1～5 分与可选文字说明，提交后只读。
- 反馈提交前明确说明评分和文字说明会向管理员展示；私人问答的问题、回答和来源不会展示。
- `/admin` 同时由前端角色守卫和后端 `require_admin` 保护，普通用户进入 `/forbidden`。
- 管理员可以启停账号、管理公共文档、查看就绪状态与失败摘要，并筛选反馈；私人文档和私人反馈上下文均脱敏。

## 安全注意事项

- 不在前端环境变量中放置 LLM、Embedding、数据库或 JWT 签名密钥。
- `VITE_` 变量会进入浏览器构建产物，只能用于公开配置。
- 文档预览生成的 HTML 必须经过 DOMPurify 清理。
