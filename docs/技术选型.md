# CodeMind 技术选型

## 1. 总体方案

CodeMind 采用前后端分离架构：

- 前端：Vue 3 + Vite
- 后端：FastAPI
- 业务数据库：MySQL
- 向量数据库：Chroma
- 大模型能力：在线 LLM API + Embedding API

## 2. 选型理由

### Vue 3 + Vite

Vue 3 开发效率高，适合快速构建后台管理和问答类页面。Vite 启动速度快，配置简单，适合实训项目快速迭代。

### FastAPI

FastAPI 与 Python AI 生态结合紧密，便于接入文档解析、向量化、Chroma、在线大模型 API 等能力。同时 FastAPI 自动生成 OpenAPI 文档，有利于前后端联调和答辩展示。

### MySQL

MySQL 用于保存用户、文档、切片元数据、问答历史和反馈等结构化业务数据，便于进行传统数据库设计与管理。

### Chroma

Chroma 用于保存文档切片向量，并提供语义相似度检索能力。MySQL 和 Chroma 分工明确：MySQL 保存业务数据，Chroma 保存向量索引。

### 在线大模型 API

在线 API 可以降低本地部署模型的硬件压力，使项目重点放在 RAG 流程、检索质量和系统交互上。
