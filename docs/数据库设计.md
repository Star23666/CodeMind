# CodeMind 数据库设计

## 1. 数据存储划分

- MySQL：保存结构化业务数据，例如用户、文档、问答历史、反馈。
- Chroma：保存向量数据和文档切片检索索引。

## 2. MySQL 表设计

### users

用户表，保存用户名、密码哈希和角色信息。

### documents

文档表，保存上传文档的文件名、类型、路径、处理状态和切片数量。

### document_chunks

文档切片元数据表，保存切片编号、对应文档、Chroma 向量 ID 和页码等信息。

### chat_sessions

会话表，保存用户的一组连续问答记录。

### chat_messages

消息表，保存用户问题、系统回答和来源引用 JSON。

### feedback

反馈表，保存用户对回答的评分和文字反馈。

## 3. Chroma 元数据设计

每个向量记录建议包含：

```text
chroma_id
document_id
document_name
chunk_index
page_number
source_text
```

这样系统在生成回答后，可以根据检索结果展示来源依据。
