# CodeMind 需求分析

## 1. 项目背景

计算机专业知识体系庞大，包含操作系统、计算机网络、数据库、数据结构、编程语言、软件工程等多个方向。传统检索方式依赖关键词匹配，难以直接回答学习者的具体问题。CodeMind 计划基于 RAG 技术构建计算机知识库问答系统，使用户可以通过自然语言提问获取带来源依据的回答。

## 2. 系统角色

- 普通用户：上传或浏览学习资料，进行知识库问答，查看答案来源和历史记录。
- 管理员：管理文档、重建知识库索引、查看系统运行状态和用户反馈。

## 3. 功能需求

- 文档上传：支持上传计算机知识相关 PDF、DOCX、Markdown、TXT 等资料。
- 文档解析：提取文档文本内容，保留文档名、页码、段落等元数据。
- 知识库构建：对文本进行切分、向量化，并写入 Chroma 向量数据库。
- 智能问答：根据用户问题检索相关知识片段，再调用在线大模型 API 生成回答。
- 来源引用：在回答中展示参考文档、片段内容、页码或切片编号。
- 文档管理：查看文档列表、删除文档、查看处理状态。
- 历史记录：保存用户会话和问答消息，便于复习和追踪。
- 用户反馈：用户可以对回答进行评分或提交反馈，辅助后续优化。

## 4. 非功能需求

- 可追溯性：系统回答应尽量基于知识库检索结果，并展示来源依据。
- 可用性：前端界面应简洁清晰，支持常见文档上传和问答操作。
- 性能要求：在小规模实训知识库下，常规问答应在数秒内返回结果。
- 安全性：API Key、数据库密码等敏感配置不得写入代码仓库。
- 可维护性：前后端分离，业务数据库和向量数据库职责清晰。
