# CodeMind 系统架构设计

## 1. 架构概览

```text
用户
  ↓
Vue 3 前端
  ↓
FastAPI 后端
  ↓
业务服务层
  ├─ 文档解析服务
  ├─ 文本切分服务
  ├─ Embedding 向量化服务
  ├─ RAG 问答服务
  └─ 大模型调用服务
  ↓
数据层
  ├─ MySQL：用户、文档、问答历史、反馈
  └─ Chroma：文档切片向量和检索索引
```

## 2. 文档入库流程

```text
上传文档
→ FastAPI 接收文件
→ 解析文档文本
→ 文本切分
→ 调用 Embedding API 生成向量
→ 向量写入 Chroma
→ 文档信息和切片元数据写入 MySQL
```

## 3. RAG 问答流程

```text
用户提问
→ 后端接收问题
→ 生成问题向量
→ Chroma 检索相关片段
→ 拼接 Prompt
→ 调用在线大模型 API
→ 返回答案和引用来源
→ MySQL 保存问答历史
```

## 4. 模块划分

- 前端展示模块：负责文档上传、知识库列表、问答界面和历史记录展示。
- API 接口模块：负责接收前端请求并进行参数校验。
- 文档处理模块：负责文件保存、内容解析和文本切分。
- 向量检索模块：负责向量生成、Chroma 写入和相似片段检索。
- 大模型调用模块：负责构造 Prompt 并调用在线大模型 API。
- 数据持久化模块：负责 MySQL 中业务数据的增删改查。
