# CodeMind 已知问题与后续计划

本文档集中记录当前版本已经确认但尚未完成的事项。功能说明以代码和 API 文档为准；这里不重复罗列已完成能力，也不把第一版明确排除的能力误写成程序缺陷。

最后核对日期：2026-07-26。当前版本基于已合并 PR #46，并完成最终演示加固：退出登录会先完成未提交练习的清理；知识地图可从操作菜单返回历史列表；PDF 改用 PDF.js 预览并验证模块 worker MIME；临时数据库或网络故障不再直接清空本地登录状态；登录接口增加账号与客户端 IP 双维度限流；节点追问采用独立短超时和瞬时失败重试；指定多题型出题按配额分批生成并在合并后再次校验。

## 当前结论

- 2026-07-26 最终本地回归通过：后端 `183 passed`、前端 `5 passed`、生产构建成功、生产依赖审计为 `0` 个漏洞。
- Docker Compose 的 MySQL、后端和前端容器均健康；后端直连与 Nginx 代理 readiness 均返回 `200`，PDF.js worker、普通 JavaScript 与 CSS 的 MIME 类型已核验。
- 一次性账号真实链路验证了注册、错误登录、成功登录后的计数清理、非法聊天请求 `422`，以及连续第 9 次错误登录返回 `429` 和 `Retry-After`；测试账号已删除。
- 当前没有已知的演示阻塞问题，也没有已知的数据越权、答案提前泄露、临时练习残留或文档删除后历史来源丢失问题。
- 剩余事项主要集中在外部模型质量、真实资料泛化、端到端自动化深度和首次进入重型功能页面时的性能。

## 维护规则

1. 新问题必须写明复现环境、影响范围和证据，不只记录现象。
2. 已解决事项从本表移除，并在提交、PR 或 Issue 中保留修复记录。
3. 性能数据需要注明模型、资料规模、题量和日期，不能直接横向比较不同条件的结果。
4. API Key、Token、密码、完整 Prompt 和用户私有资料不得写入本文档。
