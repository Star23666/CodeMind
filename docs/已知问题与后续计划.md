# CodeMind 已知问题与后续计划

本文档集中记录当前版本已经确认但尚未完成的事项。功能说明以代码和 API 文档为准；这里不重复罗列已完成能力，也不把第一版明确排除的能力误写成程序缺陷。

最后核对日期：2026-07-23。当前代码基于已合并 PR #45：固定语料校验、纯向量与混合检索阈值扫描、RAG 拒答抽样、AI 出题结构基线和 40 题人工语义复核均保留；本分支完整自动化测试与前端构建结果见验收记录，既有 Docker/在线模型流程保持为发布前复验项。

## 当前结论

- AI 出题主流程已可用，权限、答案隔离、评分、来源校验和临时数据清理未发现阻塞问题。
- Issue #28 的默认私人库、公共上传确认、独立语义检索、反馈闭环、管理员中心和私人文档迁移已完成真实 Docker 验收。
- 当前没有已知的数据越权、答案提前泄露或临时数据残留问题。
- 固定质量尺子已建立；混合检索在当前固定集已达标，AI 出题进阶结构稳定性仍需改进。
- 剩余事项主要集中在在线模型质量、第一版产品边界、自动化端到端覆盖和前端性能优化。

## 维护规则

1. 新问题必须写明复现环境、影响范围和证据，不只记录现象。
2. 已解决事项从本表移除，并在提交、PR 或 Issue 中保留修复记录。
3. 性能数据需要注明模型、资料规模、题量和日期，不能直接横向比较不同条件的结果。
4. API Key、Token、密码、完整 Prompt 和用户私有资料不得写入本文档。
