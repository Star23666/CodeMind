# CodeMind 已知问题与后续计划

本文档集中记录当前版本已经确认但尚未完成的事项。功能说明以代码和 API 文档为准；这里不重复罗列已完成能力，也不把第一版明确排除的能力误写成程序缺陷。

最后核对日期：2026-07-17。核对基线：`codex/issue-18-ai-quiz`，后端自动化测试 129 项、前端生产构建、真实 MySQL/Chroma/在线模型端到端回归均已通过。

## 当前结论

- AI 出题主流程已可用，权限、答案隔离、评分、来源校验和临时数据清理未发现阻塞问题。
- 当前没有已知的数据越权、答案提前泄露或临时数据残留问题。
- 剩余事项主要集中在在线模型耗时与质量、第一版产品边界、自动化端到端覆盖和前端性能优化。

## 问题清单

| 编号 | 优先级 | 当前问题 | 影响与现状 | 建议处理 |
| --- | --- | --- | --- | --- |
| CM-01 | P1 | AI 出题耗时依赖上游模型 | 真实环境使用 4 份资料、39 个片段生成 10 道进阶题约需 77 秒。当前已有后台进度、总超时和有限重试，但模型拥堵时仍可能等待较久或失败。 | 持续记录模型、题量、首 Token、总耗时和错误类型；形成 P50/P95 数据后再调整超时、上下文预算和默认模型。 |

| CM-04 | P2 | AI 出题结果不跨标签页、浏览器或设备保存 | 第一版按 Issue #18 约定不建立练习历史。提交结果只保存在当前标签页 `sessionStorage`，关闭标签页后消失；服务端提交后立即删除会话和题目。 | 保持当前隐私友好的默认行为；若后续确认需要错题本或学习统计，再单独设计可关闭的数据留存、保留期限和删除机制。 |
| CM-05 | P2 | 主观题仅支持用户自评 | 简答题和情景应用题提供参考答案与解析，不计入客观题得分，需要用户标记“掌握”或“需复习”。 | 后续可增加带评分标准的 AI 辅助点评，但应继续与确定性的客观题分数分开展示，并明确结果仅供参考。 |
| CM-06 | P2 | 管理员反馈缺少可视化页面 | 反馈已能持久化并通过管理员 API 筛选，尚无前端统计和处理界面。 | 增加评分分布、问题筛选、详情查看和处理状态；由前端与整合负责人推进。 |
| CM-07 | P3 | 前端部分异步业务包仍较大 | G6、Element Plus 和文档预览已拆分，构建仍会提示部分 chunk 超过推荐大小。首屏不直接加载这些业务包，但首次打开相关页面时下载量较大。 | 在功能稳定后继续按页面拆包、审查依赖引入方式，并用浏览器性能数据判断是否需要替换或延迟加载。 |
| CM-08 | P3 | 自动化测试存在第三方弃用警告 | 测试通过，但 Python 3.12 环境仍会报告 `python-jose`/SQLite 日期时间相关弃用警告，暂不影响业务结果。 | 升级兼容依赖或在替换认证库时处理；在升级 Python 或 SQLAlchemy 前纳入回归。 |

## 维护规则

1. 新问题必须写明复现环境、影响范围和证据，不只记录现象。
2. 已解决事项从本表移除，并在提交、PR 或 Issue 中保留修复记录。
3. 性能数据需要注明模型、资料规模、题量和日期，不能直接横向比较不同条件的结果。
4. API Key、Token、密码、完整 Prompt 和用户私有资料不得写入本文档。
