# 前端构建优化记录

## 目标

Issue #13 要求降低首屏负载，并将 AntV G6、Element Plus 和文档预览依赖从通用入口中拆出。构建环境为 Windows、Node.js 22、Vite 6.4.3，命令为 `npm run build`。

## 实现

- 页面路由继续使用动态 `import()` 懒加载。
- 使用 `unplugin-vue-components` 和 `unplugin-auto-import` 按需引入 Element Plus 组件、消息 API 和样式。
- 通过 `manualChunks` 分离 `vendor-g6`、`vendor-element-plus`、包含 PDF.js 的 `vendor-document-preview` 和 `vendor-vue`。
- `MindMapCanvas` 进一步使用异步组件：用户只浏览地图历史列表时不加载 G6。
- PDF 原文预览从浏览器内嵌 Blob 改为 PDF.js 画布渲染；生产 Nginx 对 `.mjs` worker 使用 `application/javascript` MIME，避免模块 worker 被浏览器拒绝。
- 未命中的依赖交给 Rollup 自动共享，避免重新聚合为首屏必须下载的通用大包。

## 构建对比

| 产物 | 优化前 gzip | 优化后 gzip | 加载时机 |
| --- | ---: | ---: | --- |
| 入口脚本 | 362.02 KiB | 20.56 KiB | 首屏 |
| Vue 运行时 | 入口内 | 41.97 KiB | 首屏预加载 |
| 知识地图页面业务代码 | 435.13 KiB | 23.97 KiB | 打开知识地图 |
| 文档预览页面业务代码 | 156.03 KiB | 2.24 KiB | 打开文档预览 |
| G6 依赖 | 入口或页面混合 | 411.25 KiB | 打开知识地图 |
| Element Plus 依赖 | 入口内 | 299.86 KiB | 按页面需要加载 |
| 文档预览依赖 | 页面混合 | 261.48 KiB | 打开文档预览（含 PDF.js） |

优化后 `dist/index.html` 只预加载入口脚本、Vue 运行时和基础样式，首屏不会下载 G6 或 PDF.js。PDF.js 使文档预览功能包变大，但它仅在打开文档预览页时加载；知识地图列表也不会加载 G6 画布。

## 最终核验（2026-07-26）

- `npm test`：5 项通过；`npm run build`：成功；`npm audit --omit=dev`：0 个漏洞。
- Docker 镜像内检查到 PDF.js worker 文件，Nginx 对 worker、普通 JavaScript 和 CSS 分别返回正确 MIME 类型。
- Vite 仍会提示部分异步业务 chunk 超过 500 KiB；这是后续性能优化项，不影响首屏或当前功能正确性。

## 本地加载验证

2026-07-15 使用全新端口提供生产 `dist`，在 Codex 内置浏览器中从开始导航到 `load` 完成的墙钟时间为约 195 ms。页面标题、主导航、问答区域和默认阈值 `0.45` 均成功渲染，控制台未发现 warning 或 error。

该时间只代表本机回环网络和本次硬件环境，不能替代 VPS、移动网络或浏览器性能面板中的正式基准。验收时应同时关注首屏预加载清单和 gzip 体积。
