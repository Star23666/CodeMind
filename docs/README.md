## 当前实现快照

已完成：

- JWT 注册登录和用户资源隔离。
- 私人知识库增删改查，以及本人私人库之间的已完成文档迁移。
- 唯一全局公共知识库、跨用户公共资料协作和最小管理员管理。
- PDF、DOCX、Markdown、TXT 上传、解析、切分、Embedding 和 Chroma 入库。
- 文档库、原文预览、片段查看、重建索引和级联删除。
- 文档处理任务原子领取、重复防护、取消、重启恢复和旧索引失败保护。
- 章节感知 Embedding、问题重写、Dense + BM25 召回、RRF 融合、直接证据 rerank、RAG 回答和来源校验。
- 问答历史页面与删除原文后的来源快照保留。
- 用户反馈持久化、归属校验、重复保护、回答/历史只读入口，以及管理员筛选和私人上下文脱敏。
- 默认私人知识库、公共上传风险提示和包含文件名/目标库的提交确认。
- 独立语义检索页面，包含参数、结果位置、证据相关度、来源跳转和完整状态反馈。
- 管理员中心，包括就绪/异常概览、用户启停、公共文档治理、反馈详情和私人资料脱敏。
- JWT 注销后立即撤销旧 Token；MySQL 与 Chroma 就绪探针。
- 个人大模型配置、密钥加密、连接测试、系统模型切换，以及问答和知识地图按用户路由。
- 知识地图异步任务、历史版本、节点追问、分支扩展、学习结构和画布交互。
- 多知识库 AI 出题、后台进度、六类题型、自动评分、来源核对和临时数据清理。
- Docker Compose 本地与 VPS 部署基础能力。
- G6、Element Plus 和文档预览独立异步分包。
- 8 份固定计算机语料、64 条 RAG 标注、16 套出题期望、阈值扫描、拒答抽样和人工评分。
- 受保护 Secret 手动触发的在线质量评估工作流；普通 PR 不自动消耗额度。
- 文档格式与体积限制、Embedding 分批，以及知识地图均衡采样、来源过滤和任务取消。
- 后端自动化测试基线以当前分支完整测试结果为准。

## 文档维护规则

1. 合并功能 PR 时同步更新 README、需求、API 和 Wiki 中的实现状态。
2. “需求”与“已实现”分开描述，演示接口不能标记为持久化完成。
3. API 字段以 `backend/app/schemas/contracts.py` 为准，路由以 `backend/app/api/routes.py` 为准。
4. 测试数量以实际执行 `python -m pytest -q` 的结果为准。
5. 数据库结构改变时同时提交 `schema.sql` 和已有数据库迁移脚本。
6. 文档、日志、截图和 Wiki 中不得出现 API Key、密码、Token 或完整 `.env`。
